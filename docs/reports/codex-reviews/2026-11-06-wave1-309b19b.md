2. **P1 - Delayed ETW events are treated as fresh ownership evidence.** [flow/etw.rs:408](F:/Projects/Code/Sieve/.claude/worktrees/wave-1/engine/crates/sieve-engine/src/flow/etw.rs:408) timestamps events with callback-time `monotonic_ms()`, ignoring their occurrence timestamp. **Scenario:** process A closes a UDP socket; its event is delayed beyond two seconds; process B reuses the tuple and closes before table lookup → A’s newly delivered event attributes B’s traffic to A, potentially borrowing A’s Off exemption. Age evidence using the event timestamp. [Microsoft documents `EventHeader.TimeStamp` as occurrence time.](https://learn.microsoft.com/en-us/windows/win32/api/evntcons/ns-evntcons-event_header)

3. **P1 - Expired NAT matches can indefinitely suppress valid host attribution.** [stack/relay.rs:167](F:/Projects/Code/Sieve/.claude/worktrees/wave-1/engine/crates/sieve-engine/src/stack/relay.rs:167) checks known owners against `held_match`, whose index changes only during a requested NAT read. **Scenario:** a cached guest session ends, then an exempt host app reuses its external tuple; subsequent flows all have owners → no fresh read occurs, the stale NAT entry forces `OwnerAndNat`, and the host app loses its exemption. Even a received WinNat deletion does not update this separate index. Validate cached positive matches before treating them as contradictions.

4. **P2 - Every routing run abandons its COM cleanup guard.** [flow/nat/os.rs:397](F:/Projects/Code/Sieve/.claude/worktrees/wave-1/engine/crates/sieve-engine/src/flow/nat/os.rs:397) calls `mem::forget(apartment)`. **Scenario:** enable routing, perform NAT queries, disable routing, repeat → each reader initializes COM but exits without `CoUninitialize`, bypassing apartment/resource cleanup. Keep the guard alive until after the thread’s sources and directory are dropped. [Microsoft requires balanced initialization and cleanup.](https://learn.microsoft.com/en-us/windows/win32/api/combaseapi/nf-combaseapi-couninitialize)

5. **P2 - Attribution capacities lack the required derivation.** [flow/etw.rs:45](F:/Projects/Code/Sieve/.claude/worktrees/wave-1/engine/crates/sieve-engine/src/flow/etw.rs:45) introduces `ETW_RING_CAP = 4096`; [flow/nat.rs:49](F:/Projects/Code/Sieve/.claude/worktrees/wave-1/engine/crates/sieve-engine/src/flow/nat.rs:49) introduces `WINNAT_TABLE_CAP = 4096`.
