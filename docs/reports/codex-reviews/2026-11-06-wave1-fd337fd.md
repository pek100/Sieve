   The new fallback creates an enforceable `pid N` app key. Turn off an unnamed worker at PID 3300, then restart Windows: an unrelated hidden process assigned PID 3300 inherits that persisted exemption and bypasses blocking rules. Previously, an unreadable, unidentified process received no exemption key. PID-only exemptions must be scoped to a process lifetime or refused.

2. **P2 - Account type does not establish which row the app displays.** `engine/crates/sieve-engine/src/flow/flows.rs:398–399`  
   A SYSTEM process whose DACL permits the user to query its executable appears under its product name in the app, but this predicate forces the engine to use its service/PID label. Turning that product row Off therefore stops exempting its traffic. Windows checks process access against the [process DACL](https://learn.microsoft.com/en-us/windows/win32/procthread/process-security-and-access-rights), not these SID prefixes. The comment’s account-to-readability claim is **reported, not observed**: the constructed tests assume that correspondence, and the changed live note explicitly leaves it unmeasured.
