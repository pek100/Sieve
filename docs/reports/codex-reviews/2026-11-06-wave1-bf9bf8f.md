2. **P1 — The production log has no producer.** `src/components/sieve/log/log-screen.tsx:72` promises rows as apps connect, but the merged engine never constructs or sends `EngineMessage::Log`; its subscription still sends only flows. **Scenario:** enable routing and generate connections, including blocked ones → `/log/` remains “Nothing yet” indefinitely. The mock and stand-in pipe tests conceal this missing integration.

3. **P2 — Failed rollback silently leaves a supposedly rejected rule persisted.** `src/components/sieve/log/use-log.ts:109` suppresses the rollback write’s rejection and immediately reports “Nothing was added.” **Reproduced sequence:** rule save fails → an already-queued unrelated settings save succeeds with the optimistic rule included → rollback save fails. Memory contains no rule, disk contains the rule, and restarting restores it despite the failure notice. Await and report rollback failure.

4. **P2 — An outstanding read repopulates a paused, cleared log.** `src/data/log-controller.ts:48` checks only disposal after awaiting the tail. **Reproduced sequence:** start a read at cursor 1 → pause → clear → resolve the read with sequence 2. The log becomes `{paused: true, cursor: 2, rows: [2]}`. Invalidate pending reads when pausing or clearing, and preserve the intended cursor semantics.

5. **P2 — Synthesized URLs discard the connection’s port.** `src/core/log.ts:128` constructs HTTPS URLs using only the host. **Scenario:** a host-level TLS row has `host: "service.example"`, `remote: "192.0.2.1:8443"` and `url: null` → Copy URL and the report seed become `https://service.example/`, targeting port 443 instead of 8443.

6. **P2 — Log limits lack the derivation required by standard 1.** `src/core/log.ts:10` introduces `LOG_POLL_MS=1000`, `LOG_RING=2000` and `LOG_SHOWN=200`; corresponding arbitrary limits include `ENGINE_LOG_CAP`, `LOG_PER_FRAME`, `LOG_URL_MAX` and `LOG_RULE_MAX`. Neither repeating these values in the plan nor testing their boundaries derives them from a budget or retention requirement. **Scenario:** append 2,001 distinct rows → the oldest becomes unsearchable solely because of the unexplained 2,000-row cutoff. The document explicitly leaves memory measurement unverified.
